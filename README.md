# AMD_DLSS5

> An open-source project focused on experimenting with DLSS-related technologies on AMD GPUs.

## 📖 项目简介

AMD_DLSS5 面向 AMD GPU 用户，主要研究和实践在 AMD 硬件环境下使用 DLSS 相关技术，并提供安装、配置和使用说明。

项目重点关注实际运行效果、参数调试、兼容性测试以及闪烁、拖影、重影等问题的排查与优化。

> **说明：** 本项目是独立的社区开源项目，与 AMD、NVIDIA 或任何游戏发行商没有官方关联，也不代表任何相关厂商的立场或支持。

---

## ✨ 项目特点

- AMD GPU 环境下的 DLSS 相关技术实践
- 提供安装、配置和使用说明
- 记录实际测试结果和参数调整

## ⚙️ 配置说明

当前配置参数说明：

| 参数 | 释义 | 建议值 |
| --- | --- | --- |
| Enabled=0 | 总开关0= 关闭补丁，完全不生效1= 开启 DLSS5‑NR 神经网络滤镜 | 玩游戏不用就保持 0；测试改为 1 |
| LocalTone=0 | 局部光影重塑强度AI 重新调整画面局部明暗、对比度。数值越高，明暗对比改动越大；过高画面发灰、色偏、泛白。 | 0‑0.3，不要超过 0.4 |
| LocalStructure=0.000 | 物体细节增强强度AI 复原纹理、阴影、物体细节。数值太高会出现涂抹、噪点、鬼影。 | 0‑0.3，不要拉满 1.0 |
| SkinStructure=1.000 | 人物皮肤专项处理专门处理人脸、皮肤。1.0 会过度磨皮，人脸糊成塑料；降低会保留皮肤纹理。 | 0.7‑0.8 最佳 |
| UseAutoMask=1 | 自动遮罩1 开启：保护 UI、血条、字幕，不让 AI 滤镜把界面弄坏。0 会把游戏 UI 一起处理，界面错乱。 | 必须 = 1，不要改 0 |
| ToneChannels=0 | 色调通道控制，0 = 全部色彩通道生效，普通用户无需改动。 | 固定 0 |
| Scale=0.03125 | AI 内部处理缩放系数，底层参数，修改直接花屏、画面崩坏。 | 禁止修改 |
| Temporal=1 | 时间降噪（帧累积）1 开启：利用前后帧消除闪烁、噪点；0 关闭画面疯狂闪烁。 | 必须 = 1 |
| Tonemap=-1 | 曝光 / 色调映射。‑1= 继承游戏本身曝光设置；不要填 0/1，会强行篡改游戏 HDR。 | 固定‑1 |
| UseFsrInputs=1 | 读取 FSR/OptiScaler 运动矢量。如果你同时在用 OptiScaler 超分工具，设置 1；没有用 OptiScaler 就改成 0，避免冲突报错 | 不用 OptiScaler 填 0 |
| UseDepth=1 | 启用深度缓冲。AI 需要深度信息区分远景近景；改成 0 远近错乱、重影。 | 必须 = 1 |
| Interop=1 | DX12 显卡资源互操作，AMD 显卡专用底层开关。 | 固定 1，不要改动 |
| Inline=0 | 渲染模式【最重要】0=Async 异步模式：仅适合截图、静止画面，玩游戏会卡顿拖影闪烁2=Inline 同步模式：正常游玩游戏用这个 | 游戏游玩：Inline=2截图临时切换Inline=0 |
| HipDevice=-1 | 显卡设备选择。‑1 = 自动识别显卡；不要手动填数字，识别错直接黑屏。 | 固定‑1 |

> **注意：** 推荐值基于当前测试环境。不同 GPU、驱动、游戏和运行环境可能存在差异，请以实际测试结果为准。
